# Japanese Knife Steel Reference Guide

An interactive metallurgical matrix for comparing Japanese knife steels across carbon, stainless, semi-stainless, and powder-metallurgy categories.

## Features

- 21 steel entries spanning four categories
- Sortable columns for all performance metrics
- Filter by steel category
- Meter-based display for performance properties
- ¥-based cost indicator

## Steel properties

| Column | Description |
|--------|-------------|
| Max Sharpness | Peak geometric edge fineness achievable |
| Corrosion Res. | Resistance to rust and oxidation |
| Edge Retention | How long the edge holds before dulling |
| Toughness | Resistance to chipping and fracture |
| Ease of Sharp. | How readily the steel responds to a whetstone |
| Max Hardness | Maximum achievable HRC hardness range |
| Relative Cost | Approximate price tier (¥ = budget, ¥¥¥¥ = premium) |
